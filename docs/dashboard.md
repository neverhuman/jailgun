# Concept dashboard

Run `jailgun setup` to start or reuse the local daemon and open a single-use
pairing link. The dashboard uses an HttpOnly session cookie; it does not save
an operator credential in browser storage or append one to a WebSocket URL.
See [CLI setup](cli.md) and [authentication](authentication-upgrade.md).

## Connect an account

In Accounts, enter the email for an account you control. Complete ChatGPT's
normal login and verification in the dedicated browser window. Jailgun waits
for an authenticated account observation. Confirm the displayed identity and
choose either the account's current model or a specifically observed model.
An unavailable configured model requires attention rather than substitution.

The profile remains in the private runtime directory. Reconnect an expired
account from the same screen; completed results remain available. The current
desktop experience uses a graphical session. On Linux servers, start with
`--server-browser` and choose **Open login view** in Accounts. See
[server login](server-login.md) for display prerequisites and SSH forwarding.
Live Linux/macOS acceptance remains pending.

## Explore and recover

New concept accepts the concept, optional constraints, an account, five to ten
perspectives, and editable criteria whose positive integer weights total 100.
All candidates receive those criteria. A failed or interrupted submission keeps
its idempotency key while the request stays identical, so a retry cannot create
a second run. Changing the request creates a new submission key.

Run progress shows saved stage and candidate states, submission usage, account
capacity, pacing/cooldown times, and deadlines. Pause stops new submissions;
already accepted work may finish. Resume retries eligible failed candidates.
An explicit **Continue with … complete candidates** action appears only when
at least three complete candidates are available, none remain active, and no
reduction stage has begun. Partial text remains partial. Cancellation retains
captured results and asks the supervisor to stop the run's owned conversations.

The browser retains the concept draft and selected run during navigation and
session re-pairing. Drafts are kept only in memory; reloading or closing the tab
clears an unsubmitted draft. Persisted runs survive browser and daemon restarts.

## Read and export

Results includes full and partial candidate responses, summaries, the comparison,
synthesis, critique, revised final concept and result manifest. The reader checks
artifact length and SHA-256 before rendering. Markdown preserves code, lists,
headings and links while raw HTML is disabled and remote images are not loaded.
Large outputs remain downloadable when they exceed the reader's display limit.

The comparison shows model-generated scores, rationales, disagreements and
uncertainty. They are judgments, not independently established facts. Subset
results identify excluded candidates. Download individual registered artifacts,
or use `jailgun runs export <run-id> --out <directory>` for a verified directory.

## Automation and demonstrations

Expand **Automation access for CLI and MCP** in Accounts to create an explicitly
account-scoped token. Save the secret when shown; it is not displayed again.
Revocation requires confirmation because clients using that token immediately
lose access. See [MCP](mcp.md) for client configuration.

`?demo=1` selects clearly labelled synthetic data without making API requests.
It cannot submit work. Demo records are generated by executing the Rust storage
state machine, including an explicit subset decision. An unavailable live API
never substitutes demonstration data.

`?advanced=1` opens the retained archive/deployment monitor. Its own demo is
`?advanced=1&demo=1`. Advanced execution remains separately authorized; concept
submission never enables deployment.

## Verification

`bash ops/ci/node.sh` runs component tests and builds the dashboard.
`bash ops/ci/ux-qa.sh` captures desktop/mobile screenshots, DOM snapshots and axe
results from Chromium, including keyboard skip-link navigation. The end-to-end
lane additionally drives five- and ten-candidate workflows through the built UI,
production Rust service and real sandboxed Chrome against the interactive
synthetic provider. These are synthetic integration checks, not live ChatGPT
acceptance evidence.
